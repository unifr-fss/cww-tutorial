# Tutorial 1 - Soft Circuits

This folder contains the introductory Jupyter Notebook tutorial on soft circuits and e-textiles.

## Files

- `Tutorial 1 - Soft Circuits Introduction.ipynb`  
  Main Jupyter Notebook file.

- `Tutorial 1 - Soft Circuits Introduction.html`  
  HTML export of the notebook for browser-based viewing after download or future GitHub Pages use.

- `Tutorial 1 - Soft Circuits Introduction.pdf`  
  PDF export for quick review and sharing.

- `soft_computing_pictures/`  
  Image folder used inside the notebook.

## Description

This tutorial introduces the basic idea of soft circuits and e-textiles. It shows how conductive thread, a power source, LEDs, switches, and textile materials can be used to build simple fabric-based circuits.

The tutorial also includes a short optional note on flex sensors as a bridge toward later sensor-based work with Raspberry Pi, EmotiBit, and fuzzy linguistic interpretation.
