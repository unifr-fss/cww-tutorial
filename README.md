# CWW-Tutorials

This tutorial is part of the course **Computing with Words**
for the [Swiss Joint Master of Science in Computer Science](https://mcs.unibnf.ch/). 
It introduces the use of Computing with Words with the use of Raspberry Pi's and Emotibit.

Jupyter Notebook tutorials are covering soft circuits, Raspberry Pi, USB &amp; 
Adafruit Speaker-Mic audio input/output, EmotiBit sensors, 
and fuzzy linguistic data processing.

## Tutorials
The goal of the tutorials is to give you a kick-start into the use of the different parts mentioned before. 
**Tutorial 1** serves an illustrative introduction and does not need to be copied.
It gives you an idea about electrical circuits and how they can be used on textile examples.
This can be a possible inspiration for the later personal project.

From **Tutorial 2** onwards, go through the Jupyter Notebook files. You'll find detailled
instructions on how to get started with the different parts.

Furthermore, in **Tutorial 2** you'll find an extensive explanation on how to set up the raspberry pi.
There is a Jupyter Notebook as well as a PDF version. Go though either one and take your time.
The software takes a few minutes to load, once you've placed it on the SD-Card. So be patient with the first installation.

Also take your time when you set up the EmotiBit introduced in **Tutorial 5.1**.
Do it one step at the time and read the instructions carefully.
